# Oi, eu sou o Gabriel 👋

Dev full-stack em Brasília. Construo sistemas que resolvem um problema concreto de um negócio real, e eles **estão em uso**: o sistema de uma clínica médica, o PDV de uma creperia e o site de um blog bilíngue.

**Stack principal:** Node.js · Express · React · Next.js · TypeScript · PostgreSQL · SQLite · Capacitor (Android) · Electron · nginx · Linux/VPS · Python · WordPress.

Integro **IA** onde ela poupa trabalho de verdade, com limite de cota, timeout e saída para um humano: leitura de documentos, atendimento por WhatsApp e tutor de estudos.
